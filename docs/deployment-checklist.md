## 1. Мэдээллийн сангийн нөөц хувилбар (заавал)

## 2. Шифрлэлтийн түлхүүр үүсгэх (заавал, нэг удаа)

Өвчтөний мэдээлэл, эмчийн тэмдэглэл, регистрийн дугаар, утас, хаяг зэрэг мэдрэг
талбарууд AES-256-GCM аргаар шифрлэгдэнэ. Түлхүүр үүсгэх:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

- Гарсан утгыг **нууц үгийн менежерт** (1Password, Bitwarden г.м) «Bio-Dosha ENCRYPTION_KEY»
  нэрээр хадгална. Түлхүүрээ алдвал шифрлэгдсэн мэдээллийг сэргээх **боломжгүй**.
- Түлхүүрийг хэзээ ч солихгүй, хэнд ч илгээхгүй.

## 3. Netlify орчны хувьсагчид

Netlify → Site configuration → **Environment variables** → Add a variable
(scope: Builds, Functions, Runtime):

| Хувьсагч | Утга | Тайлбар |
| --- | --- | --- |
| `ENCRYPTION_KEY` | 2-р алхмын утга | Заавал |
| `APP_URL` | `https://<таны-сайт>.netlify.app` | Урилга, нууц үг сэргээх холбоосын хаяг |
| `RESEND_API_KEY` | (заавал биш) | Имэйл автоматаар илгээх бол resend.com-оос |
| `EMAIL_FROM` | (заавал биш) | Жишээ нь `Bio-Dosha-12 <no-reply@таны-домэйн>` |

`RESEND_API_KEY`, `EMAIL_FROM` тохируулаагүй үед систем урилга болон нууц үг сэргээх
холбоосыг удирдлагын төв дээр харуулна; та түүнийг хуулж, Gmail эсвэл Viber-ээр илгээнэ.

## 4. Migration ажиллуулах

Production-ий `DATABASE_URL`-ыг Netlify-аас (Environment variables → `DATABASE_URL` →
утгыг харах) хуулна. PowerShell дээр:

```powershell
$env:DATABASE_URL = "<production DATABASE_URL>"
npx prisma migrate deploy
```

«All migrations have been successfully applied» гэж гарвал болсон. Энэ migration:
- байгууллага, гишүүнчлэл, багц, захиалга, урилга, аудитын хүснэгтүүдийг нэмнэ;
- 5 багц (Үнэгүй, Гэр бүл, Эхлэл, Мэргэжлийн, Байгууллага) үүсгэнэ;
- өмнөх эмчийн эрхтэй хэрэглэгч бүрт өөрийнх нь «… — эмнэлэг» байгууллагыг үүсгэж,
  өвчтөнүүдийг нь тийш шилжүүлнэ. Юу ч устгахгүй.

## 5. PR-ийг merge хийх

## 6. Туршилтын бүртгэлүүдийг цэвэрлэх

Одоогийн бүх бүртгэл туршилтынх тул устгана. Эхлээд **зөвхөн харах** горимоор:

```powershell
npx tsx scripts/reset-accounts.ts --include-audit-log
```

Жагсаалтыг шалгаад, зөв бол бодитоор устгана (нөөц файл OneDrive-аас гадуур, системийн
түр хавтсанд бичигдэж, зам нь дэлгэцэнд гарна):

```powershell
npx tsx scripts/reset-accounts.ts --apply --confirm=DELETE-ACCOUNTS --include-audit-log
```

Нөөц файлд эрүүл мэндийн мэдээлэл байгаа тул шалгасны дараа устгана.

## 7. Супер админ үүсгэх

```powershell
npx tsx scripts/bootstrap-superadmin.ts <таны имэйл> --apply --base-url=https://<таны-сайт>.netlify.app
```

Скрипт **нэг удаагийн урилгын холбоос** хэвлэнэ (24 цаг хүчинтэй). Хэрэв «An account with
this email already exists» гэж зогсвол: бүртгэл нээлттэй тул өөр хүн тэр имэйлээр урьдчилан
бүртгүүлсэн байж болно. Та өөрөө үүсгээгүй бол 6-р алхмыг давтаж устгаад дахин ажиллуулна.
Холбоосыг нээж:
1. нэр, нууц үгээ оруулж бүртгэлээ үүсгэнэ;
2. автоматаар нээгдэх «2 шаттай нэвтрэлт» хуудсаар Google Authenticator / Microsoft
   Authenticator апп-д QR кодыг уншуулна;
3. **10 нөөц кодыг** хэвлэж эсвэл нууц үгийн менежерт хадгална (утсаа алдвал хэрэгтэй).

Дараа нь `/admin` — **Удирдлагын төв** нээгдэнэ.

## 8. Ноён Төмөрбаатарын бүртгэл

**Эмчийн (байгууллагын) бүртгэл — эмчийн ажлын имэйл**

1. Удирдлагын төв → **Байгууллагууд** → **Байгууллага нэмэх**.
2. Нэр: жишээ нь «Төмөрбаатар Оточ эмнэлэг», төрөл: Эмнэлэг, эзний имэйл: эмчийн ажлын
   имэйл, төлөв: **Идэвхтэй (баталгаажсан)**, багц: апп-ын
   эзэмшигч тул **Байгууллага (Enterprise)** багцыг зөвлөж байна.
3. Гарч ирэх урилгын холбоосыг хуулж, Төмөрбаатар эмчид Gmail эсвэл Viber-ээр илгээнэ.
   Тэр холбоосоор бүртгэлээ үүсгэж, 2 шаттай нэвтрэлтээ тохируулсны дараа өвчтөний
   бүртгэл, тайлан, гишүүдээ урих боломжтой болно.

**Хувийн бүртгэл — хувийн имэйл**

1. Тэр өөрөө `/register` хуудсаар **Хувийн** бүртгэл үүсгэнэ (өмнөх бүртгэл 6-р
   алхмаар устсан тул дахин бүртгүүлнэ).
2. Хүсвэл Удирдлагын төв → **Хэрэглэгчид** → тухайн хэрэглэгч → **Багц солих** →
   «Гэр бүл» багц оноож болно.

## 9. Хуучин мэдээллийг шифрлэх (зөвхөн өгөгдөл үлдээсэн бол)

6-р алхмаар бүгдийг устгасан бол шаардлагагүй. Өгөгдөл үлдээсэн бол:

```powershell
$env:ENCRYPTION_KEY = "<2-р алхмын түлхүүр>"
npx tsx scripts/encrypt-existing-data.ts          # тоолж харна
npx tsx scripts/encrypt-existing-data.ts --apply  # шифрлэнэ
```

## 10. Эцсийн шалгалт

Удирдлагын төв → **Систем** хуудсанд бүх мөр ногоон байх ёстой: шифрлэлтийн
түлхүүр, нэвтрэлтийн нууц, сайтын хаяг, мэдээллийн сан, сүүлийн migration
`20261027000000_organizations_plans_security`, шифрлэгдээгүй мэдрэг утга 0.

Ажиллаж дууссаны дараа PowerShell цонхыг хаана (DATABASE_URL, ENCRYPTION_KEY санах ойгоос арилна).

## Асуудал гарвал (rollback)

1. Netlify → Deploys → өмнөх амжилттай deploy → **Publish deploy**.
2. Neon → 1-р алхмын `backup-…` салбараас сэргээнэ (эсвэл `DATABASE_URL`-ыг түр
   тэр салбар руу заана).
3. Алдааны мэдээлэл: Netlify → Logs → Functions.
